## Running Locally (VS Code)

This project requires a
[local Flutter SDK install](https://docs.flutter.dev/get-started/install).
Use the included launch configurations for interactive debugging
(breakpoints, variable inspection, the Flutter Inspector, hot reload via the
VS Code UI).

1. Install the
   [Flutter extension](https://marketplace.visualstudio.com/items?itemName=Dart-Code.flutter)
   for VS Code (recommended automatically via `.vscode/extensions.json`).
2. Run `flutter pub get` once in the project root.
3. Open the **Run and Debug** panel (`Cmd+Shift+D`) and pick one of the
   preconfigured targets from `.vscode/launch.json`, or press `F5`:
   - **ben_knight_website2 (Chrome, Debug)** — full debugging support with
     breakpoints and hot reload.
   - **ben_knight_website2 (Chrome, Profile)** — for performance profiling.
   - **ben_knight_website2 (Chrome, Release)** — closest to a production
     build.

The app launches in a dedicated Chrome window. Saving a file hot-reloads
automatically, or use the Run panel's restart/hot-reload buttons.
